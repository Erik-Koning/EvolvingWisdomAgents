# Talk description v3 — self-evolving agent / governance framing

**Suggested title:** *Sleep, Growth, and a Constitution: shipping an agent that rewrites itself*

**Angle:** the learning loops and safety machinery, for an AI-engineering audience. Leads with
the frozen-vs-drifting memory trade; the constitution and evidence rule are the hook.

---

Agents that learn from their users usually face a bad trade: memory that's frozen, or memory
that drifts — and it's opaque either way. This talk shows a third option: an agent whose
behavior is a wisdom graph it tends itself, under graduated human governance. The agent
writes, merges, and retires its own rules from conversation and feedback — dedup-checked,
versioned, audited. On a rhythm borrowed from biological memory it sleeps: consolidating
near-duplicates, re-ranking reinforced lessons, and in deep sleep proposing new categories,
gated by a routing-regression check so evolution can't silently steal traffic. Identity sits
behind a constitution: the charter amends only under citation-weighted evidence pressure,
within a drift cap and an inversion check, with a human approving every amendment. Forgetting
requires receipts — a verbatim user quote, mechanically verified — so the agent can't launder
its own inferences into the authority to forget. Expect a live demo of a graph learning,
sleeping, growing, and petitioning its own constitution — and the design rules that make
self-modification shippable.
